# KlipScen website (redesign prototype)

Static preview of the new KlipScen site: plain HTML, CSS and a little vanilla JS, no build step.

| Page | File |
|---|---|
| Home | `index.html` |
| Services | `services.html` |
| Work | `work.html` |
| Process | `process.html` |
| Contact | `contact.html` |

- `assets/site.js`: Work page filters and the contact form confirmation (the form does not send anything yet).
- Brand: black `#0A0A0A`, deep gold `#A67C2E`, ivory `#F6F3EC`; Bebas Neue, Inter and Roboto Mono.
- Preview locally: `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

Open items: real showreel and project thumbnails, WhatsApp, Instagram and privacy links, and the bracketed placeholders (turnaround, revision rounds).
